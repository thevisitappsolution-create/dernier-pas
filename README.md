# Lastep

Le duel de stratégie où les cases s'usent. Deux pions chacun, un plateau 5×5, le dernier qui peut bouger gagne.

Jouer : https://lastep.app

## Langues (FR / EN)

Tout texte visible doit passer par `T("texte français")`. La traduction anglaise est dans `lang-en.js` (clé = texte français exact). La langue suit le téléphone, et le joueur peut la changer dans Réglages.
